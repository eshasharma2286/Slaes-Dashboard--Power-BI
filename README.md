# Slaes-Dashboard--Power-BI
Project Title- Sales Dashboard
Short Description- Analyzed E-Commerce Sales Data, Created Sales dashboard using Power BI
Tech Stack- The Dashboard was built using Power BI Desktop
Features/Highlights- Track Sales for a business, Used two Excel Tables for Order Id, Customer Name, State, Amount and other related data to import. Created Dashboard using Charts- Stack Column Chart, Bar chart, Donut chart, Cards, Slicers, Text Box for Headings
